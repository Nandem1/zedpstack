I have enough to assess all five focus areas. A few confirmations on the subtle ones:

- **Reviewer validation relaxations are keyed to the wrong role ids.** `src/validation.mjs:19,105-106,138` gate the relaxations (min length 12, single-line allowed, skip read-signal) on `role === 'interrogate-reviewer' | 'reflect-reviewer'`, but the actual step roles are `interrogate-reviewer-a/b/c` and `reflect-reviewer-judgment/tooling/divergent` (`playbooks/interrogate-review/playbook.json:9,17,25`, `playbooks/reflect-session/playbook.json:10,18,26`). `src/run.mjs:272` passes `stepDef.role` verbatim, so the relaxations are dead for every real reviewer.
- **Effort is dead end-to-end.** `bindingsFromSheet` writes `effort` (`src/modelSheet.mjs:143`) but `resolveRoleBinding` returns only runtime/model/permissionProfile (`src/config.mjs:61-65`) and neither `buildClaudeArgv` nor `buildCodexArgv` emit a reasoning flag (`src/permissions.mjs:44-83`).
- **Sequential, not fan-out.** `src/run.mjs:394-421` is a `for…of` loop; independent steps (reviewers a/b/c, runners a/b) run serially.
- **Codex passes the full prompt as argv** (`src/runtimes/codex.mjs:42`, emitted in `worker.spawned.argv` at :51-60), while Claude uses stdin (`src/runtimes/claude.mjs:57`).

## Verdict
**GO-with-fixes** — architecture is sound and the read-only boundary holds, but a validation-role mismatch and the sequential-vs-fanout gap should land before a production `/zedpstack`.

## Strengths
- **Real read-only boundary, enforced before spawn.** `assertPermissionProfile` hard-rejects anything but `read-only` (`src/permissions.mjs:6-14`), Claude is constrained via `--tools Read,Grep,Glob --permission-mode dontAsk` with a pre-flight `--tools` capability probe (`src/permissions.mjs:28-65`), Codex uses the OS sandbox `codex exec -s read-only` plus stderr mutation heuristics as defense-in-depth (`src/shellSignals.mjs:51-106`), and env is allow-listed per runtime (`src/permissions.mjs:85-103`).
- **Faithful pstack-sheet alignment with graceful fallback.** `setup apply` parses the same `setup-pstack` row labels, infers runtime from slug, and *merges* into config preserving timeouts/unknown roles (`src/modelSheet.mjs:9-32`, `src/setupConfig.mjs:49-55`); missing sheet falls back to a template rather than erroring (`src/setupConfig.mjs:20-30`).
- **Deterministic resume + observable streaming.** Step-identity hashing revalidates artifacts on every pass so resume can't bypass a stale step (`src/run.mjs:162-208,392-394`), and the append-only `events.jsonl` with opt-in `--tee-events` / `--persist-stream-events` keeps hot-path logs out of disk by default (`src/events/sink.mjs:31-38`).
